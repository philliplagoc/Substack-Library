# Milestone 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Writing style:** This plan follows ASD-STE100. Sentences are short. Each sentence gives one instruction. Verbs are active.

**Goal:** Produce the two Milestone 0 outputs: a Substack compatibility doc with test fixtures, and a throwaway board prototype that settles the layout.

**Architecture:** Part A is a compatibility spike. You capture anonymized HTML from three kinds of Substack pages with a DevTools snippet. One extraction module reads metadata from those pages. Node tests prove the extraction works on the saved fixtures. Part B is a throwaway prototype. It is one HTML page with plain CSS and JavaScript. It has three columns, cards, a notes panel, and a Markdown preview. No product code is written in this milestone.

**Tech Stack:** Browser DevTools, plain HTML/CSS/JavaScript, Node 24 (`node --test`), `linkedom` (a small DOM parser for Node). No React, no bundler, no extension manifest yet.

**Spec:** `implementation-plan.md` (section "Build sequence", Milestone 0; also "Architecture", "Data model", "Export format", "Reliability", "Verification").

## Global Constraints

Copied from the spec. Every task obeys these.

- Milestone 0 comes "before product code". The prototype is throwaway. Do not reuse prototype code in Milestone 1.
- Spike output: "a short doc naming the selectors and read paths v1 relies on, and captured anonymized page fixtures for tests."
- Prototype output: "Columns, cards, notes panel, markdown preview, to settle layout before real code."
- Metadata fallback chain: "og tags, then `document.title`, then hand-edit."
- Reading time: "word count / 250 at capture; blank when the body is unreadable."
- Reliability: "Silent failure is banned throughout." Extraction functions return `null` for a missing field. They never throw.
- Export filename: `2026-08-16 - How Great Questions Change a Company (v2).md`.
- Export frontmatter keys: `title, author, publication, url, saved, read, tags`. Keys stay flat and lowercase.
- Board columns: **To Read**, **Reading**, **Processed**. Cards show title, publication, author, estimated reading time, saved date, and note/export status.
- Fixtures must not contain the reader's personal data.
- **Scope, v1:** the reader pays for no publication. Every article they read is free. v1 reads free articles and detects a paywall. It does not read a paid subscriber's article body.

## Deferred to a later version

Paid subscriptions are out of scope for v1.

- There is no `article-paid-subscribed.html` fixture. Nobody on this project can capture one.
- The paywall fixture stays. Opening a paid article you do **not** subscribe to costs nothing, and the extension must tell a teaser from a whole article. Without that check a 90-word teaser becomes a "1 min read" card, and the reader triages an article they cannot open.
- If the reader buys a subscription later: capture `article-paid-subscribed.html`, add its manifest entry, and run `npm test`. If the read paths match the free article, the fixture is the whole job.

### Task 2: Fixture capture snippet

**Files:**

**Interfaces:**

- Contract: The snippet edits a **clone** of the page. It never edits the live page.

**Why a snippet:** Substack renders pages after JavaScript runs. "View source" shows the empty shell. The console sees the finished DOM. This is the same DOM the content script will see later.

- [x] **Step 1: Write the snippet**

Create `spike/capture-fixture.js`:

```js
// Paste this whole file into the DevTools console on a Substack page.
// Then paste the clipboard into spike/fixtures/<name>.html.
//
// EDIT BEFORE USE: put your own name, handle, and email in PRIVATE_STRINGS.
(async function captureFixture() {
  const PRIVATE_STRINGS = [
    // 'Your Name', 'yourhandle', 'you@example.com',
  ];

  // Human writes: replace every private string, case-insensitive, with READER.
  // Return the redacted text. Do not throw on empty input.
  function redact(text) {
    // TODO(human)
    return text;
  }

  const clone = document.documentElement.cloneNode(true);

  // 1. Drop scripts and styles. Keep JSON-LD, it holds metadata we want to test.
  for (const el of clone.querySelectorAll('script:not([type="application/ld+json"]), style, link[rel="stylesheet"], noscript, iframe, svg, video, audio')) {
    el.remove();
  }

  // 2. Drop images and their lazy-load attributes. Fixture size matters.
  for (const img of clone.querySelectorAll('img, picture, source')) {
    img.remove();
  }

  // 3. Drop inline event handlers and tracking attributes.
  for (const el of clone.querySelectorAll('*')) {
    for (const attr of [...el.attributes]) {
      if (attr.name.startsWith('on') || attr.name.startsWith('data-track')) {
        el.removeAttribute(attr.name);
      }
    }
  }

  // 4. Redact private strings in text nodes and attribute values.
  const walker = document.createTreeWalker(clone, NodeFilter.SHOW_TEXT);
  let node;
  while ((node = walker.nextNode())) {
    node.nodeValue = redact(node.nodeValue);
  }
  for (const el of clone.querySelectorAll('*')) {
    for (const attr of [...el.attributes]) {
      const clean = redact(attr.value);
      if (clean !== attr.value) el.setAttribute(attr.name, clean);
    }
  }

  const html = '<!DOCTYPE html>\n' + clone.outerHTML;
  await navigator.clipboard.writeText(html);

  console.log('Fixture copied to clipboard.');
  console.log('URL:', location.href);
  console.log('Size (KB):', Math.round(html.length / 1024));
  console.log('Title:', document.title);
})();
```

- [x] **Step 2: [Human step] Implement `redact(text)`**

Guidance: Build one regular expression from `PRIVATE_STRINGS`. Escape regex characters in each string. Use the `gi` flags. Return `text` unchanged when the list is empty. Reference implementation for review:

```js
  function redact(text) {
    if (!text || PRIVATE_STRINGS.length === 0) return text;
    const escaped = PRIVATE_STRINGS.map((s) => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&'));
    const pattern = new RegExp(escaped.join('|'), 'gi');
    return text.replace(pattern, 'READER');
  }
```

```js
// Runs in the DevTools console and in Node. Assigns to globalThis.spike.
// Pure functions. No network. No file access. Never throws.
(function () {
  const SELECTORS = {
    // Update from spike/README.md after the survey.
    body: '.body.markup',
    paywall: '.paywall',
    saveButton: 'button[aria-label*="Save"], button[aria-label*="Unsave"]',
    likeButton: 'button[aria-label*="Like"]',
  };

  function meta(doc, selector) {
    const el = doc.querySelector(selector);
    const value = el && el.getAttribute('content');
    return value && value.trim() ? value.trim() : null;
  }

  function jsonLd(doc) {
    const out = [];
    for (const script of doc.querySelectorAll('script[type="application/ld+json"]')) {
      try {
        const parsed = JSON.parse(script.textContent);
        if (Array.isArray(parsed)) out.push(...parsed);
        else out.push(parsed);
      } catch (_) {
        // Malformed JSON-LD is not our problem. Skip it.
      }
    }
    return out;
  }

  function firstNonNull(candidates) {
    for (const [source, value] of candidates) {
      if (value) return { value, source };
    }
    return { value: null, source: null };
  }

  function extractArticleMeta(doc) {
    const sources = {};
    const ld = jsonLd(doc).find((x) => x && /Article/.test(String(x['@type']))) || {};
    const ldAuthor = Array.isArray(ld.author) ? ld.author[0] : ld.author;

    const title = firstNonNull([
      ['og:title', meta(doc, 'meta[property="og:title"]')],
      ['ld:headline', ld.headline || null],
      ['document.title', doc.title && doc.title.trim() ? doc.title.trim() : null],
    ]);
    const author = firstNonNull([
      ['meta:author', meta(doc, 'meta[name="author"]')],
      ['ld:author.name', ldAuthor && ldAuthor.name ? ldAuthor.name : null],
    ]);
    const publication = firstNonNull([
      ['og:site_name', meta(doc, 'meta[property="og:site_name"]')],
      ['ld:publisher.name', ld.publisher && ld.publisher.name ? ld.publisher.name : null],
    ]);
    const canonical = doc.querySelector('link[rel="canonical"]');
    const canonicalUrl = firstNonNull([
      ['link:canonical', canonical && canonical.getAttribute('href') ? canonical.getAttribute('href') : null],
      ['og:url', meta(doc, 'meta[property="og:url"]')],
    ]);

    // Human writes: word count.
    // Find the body with SELECTORS.body. Split its textContent on whitespace.
    // Return null when the body is missing or empty. Set sources.wordCount.
    let wordCount = null;
    // TODO(human)

    const isPreview = Boolean(doc.querySelector(SELECTORS.paywall));

    sources.title = title.source;
    sources.author = author.source;
    sources.publication = publication.source;
    sources.canonicalUrl = canonicalUrl.source;

    return {
      title: title.value,
      author: author.value,
      publication: publication.value,
      canonicalUrl: canonicalUrl.value,
      wordCount,
      isPreview,
      sources,
    };
  }

  globalThis.spike = { SELECTORS, extractArticleMeta };
})();
```

    }

// Prototype only. Throwaway. Not reused in Milestone 1.
const STORAGE_KEY = 'substack-library-proto';

let state = load();
let selectedId = null;

function load() {
  const raw = localStorage.getItem(STORAGE_KEY);
  return raw ? JSON.parse(raw) : structuredClone(window.PROTO_CARDS);
}
function save() {
  localStorage.setItem(STORAGE_KEY, JSON.stringify(state));
}

function statusLabel(card) {
  const bits = [];
  if (card.notes && card.notes.trim()) bits.push('notes');
  if (card.quotes.length) bits.push(`${card.quotes.length} quote${card.quotes.length === 1 ? '' : 's'}`);
  if (card.exportVersion > 0) bits.push(`exported v${card.exportVersion}`);
  return bits.join(' · ');
}

function visibleCards() {
  const q = document.getElementById('search').value.trim().toLowerCase();
  const max = Number(document.getElementById('max-minutes').value) || 0;
  return state.filter((c) => {
    const hay = `${c.title} ${c.author} ${c.publication}`.toLowerCase();
    if (q && !hay.includes(q)) return false;
    if (max && (c.estimatedReadingMinutes == null || c.estimatedReadingMinutes > max)) return false;
    return true;
  });
}

function render() {
  const template = document.getElementById('card-template');
  const cards = visibleCards();
  for (const column of document.querySelectorAll('.column')) {
    const status = column.dataset.status;
    const list = column.querySelector('.cards');
    list.replaceChildren();
    const inColumn = cards.filter((c) => c.status === status).sort((a, b) => a.sortOrder - b.sortOrder);
    column.querySelector('.count').textContent = `(${inColumn.length})`;
    for (const card of inColumn) {
      const node = template.content.firstElementChild.cloneNode(true);
      node.dataset.id = card.id;
      node.classList.toggle('selected', card.id === selectedId);
      node.querySelector('.title').textContent = card.title;
      node.querySelector('.pub').textContent = `${card.publication} · ${card.author}`;
      node.querySelector('.minutes').textContent = card.estimatedReadingMinutes != null ? `${card.estimatedReadingMinutes} min` : '— min';
      node.querySelector('.saved').textContent = `saved ${card.savedAt}`;
      node.querySelector('.status').textContent = statusLabel(card);
      list.appendChild(node);
    }
  }
}

document.getElementById('search').addEventListener('input', render);
document.getElementById('max-minutes').addEventListener('input', render);
document.getElementById('reset').addEventListener('click', () => {

  state = structuredClone(window.PROTO_CARDS);
  selectedId = null;
  render();
});

render();

function moveCard(cardId, newStatus) {
  const card = findCard(cardId);
  if (!card || card.status === newStatus) return;
  const last = Math.max(-1, ...state.filter((c) => c.status === newStatus).map((c) => c.sortOrder));
  card.status = newStatus;
  card.sortOrder = last + 1;
  save();
  render();
}

const board = document.querySelector('.board');
board.addEventListener('dragstart', (event) => {
  const cardEl = event.target.closest('.card');
  if (!cardEl) return;
  event.dataTransfer.setData('text/plain', cardEl.dataset.id);
  event.dataTransfer.effectAllowed = 'move';
  cardEl.classList.add('dragging');
});
board.addEventListener('dragend', (event) => {
  event.target.closest('.card')?.classList.remove('dragging');
});
board.addEventListener('dragover', (event) => {
  const column = event.target.closest('.column');
  if (!column) return;
  event.preventDefault(); // Required. Without this the browser refuses the drop.
  event.dataTransfer.dropEffect = 'move';
  column.classList.add('drop-target');
});
board.addEventListener('dragleave', (event) => {
  event.target.closest('.column')?.classList.remove('drop-target');
});
board.addEventListener('drop', (event) => {
  const column = event.target.closest('.column');
  if (!column) return;
  event.preventDefault();
  column.classList.remove('drop-target');
  moveCard(event.dataTransfer.getData('text/plain'), column.dataset.status);
});

## Glossary for the learner

- **DOM:** the tree of objects the browser builds from HTML. JavaScript reads and edits it.
- **Selector:** a CSS pattern such as `.body.markup` that finds elements in the DOM.
- **OG tags:** `<meta property="og:…">` tags. Sites add them so links unfurl in chat apps. We reuse them for metadata.
- **JSON-LD:** a `<script type="application/ld+json">` block with structured data for search engines. Often more complete than OG tags.
- **Fixture:** a saved copy of real page HTML. Tests parse it offline.
- **Content script:** extension code that runs inside a web page. It sees the same DOM the console sees. Milestone 2 uses one.
- **Manifest V3:** the current Chrome extension format. Milestone 1 uses it.
